# Guia do Jogador v_1

## Início rápido

Execute `JOGAR.bat`, abra o endereço indicado e escolha Campanha.

## Formar o grupo

No Códice, selecione um comandante e duas tropas. A seleção mais antiga é
substituída quando uma terceira tropa é escolhida. Inicie um cenário.

## Batalha

- Selecione uma unidade azul ainda não ativada.
- Clique numa casa vazia para mover ou num inimigo ao alcance para atacar.
- Use o painel para trocar de modo ou emitir comandos.
- A IA realiza uma ativação e devolve o controle.
- Derrote o comandante vermelho para vencer.

Preparar Lança está disponível na interface. Investida e Escaramuça são
suportadas pelo motor e cobertas por testes de regra.
